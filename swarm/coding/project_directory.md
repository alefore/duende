## Project directory

A *project directory* contains information about a project
to extend a software product:

* `plan.md`: The project plan.
  Describes the project's goal and tasks to execute the project
  (including their state).

* `repository/`: A git repository to adjust the software product.

* `research/`: Markdown files with the output of research tasks
  (specific to this project).

* `data/`: Temporary files (specific to this project).
  These are large files which shouldn't be included in `plan.md`
  nor commited to the git repository.
